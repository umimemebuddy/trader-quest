# 🚀 TRADER QUEST: 市场大战

一个快节奏像素风格 roguelike 游戏

## 游戏介绍

你是一名普通交易员，在加密市场觉醒后进入"市场梦境"，与 KOL、庄家、金发 Boss 等敌人战斗。

## 运行方式

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

## 技术栈

- Phaser 3 (Canvas/WebGL)
- Vite (构建工具)

## 操作说明

- **WASD** - 移动
- **空格** - 攻击
- **E** - 放置矿机

## 核心机制

- 💸 金币 5 秒后消失
- 🔥 连续击杀积累 COMBO，断掉损失 50% 奖励
- ⏰ 限时商店随机出现
- 📊 牛熊市切换影响收益
